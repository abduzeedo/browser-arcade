# Bundled emulator software

Runtime files are unchanged downloads from https://cdn.emulatorjs.org/stable/data/ (EmulatorJS 4.2.3). Corresponding upstream source: https://github.com/EmulatorJS/EmulatorJS/tree/v4.2.3

Core binaries and build reports are unchanged downloads from the same CDN under cores/. Core build infrastructure and source references: https://github.com/EmulatorJS/build

Core source repositories and licenses:
- Genesis Plus GX: https://github.com/ekeeke/Genesis-Plus-GX
- FCEUmm: https://github.com/libretro/libretro-fceumm
- Gambatte: https://github.com/libretro/gambatte-libretro
- mGBA: https://github.com/mgba-emu/mgba
- SMS Plus GX: https://github.com/libretro/smsplus-gx
- Snes9x: https://github.com/libretro/snes9x

Each emulator core has its own license; the frontend license does not replace core licenses. These bundles are for the user's local emulator page.
